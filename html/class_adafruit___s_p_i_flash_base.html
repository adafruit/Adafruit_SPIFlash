Detailed Description

An easy to use interface for working with Flash memory.

If you are managing allocation of the Flash space yourself, this is the class to use as it take very little RAM.

◆ waitUntilReady()

void Adafruit_SPIFlashBase::waitUntilReady ( void  )

Block until both the write-in-progress bit and the write enable latch are clear in status register 1 (returns at once for FRAM). The latch stays set after writeEnable() until a program, erase or status register write completes or writeDisable() is called, so on transports that read the real status register, calling this after writeEnable() with none of those following blocks forever.

◆ erasePage()

bool Adafruit_SPIFlashBase::erasePage ( uint32_t  pageNumber)

Erase a 256 byte page with SFLASH_CMD_ERASE_PAGE (0x81). This command is device-specific: many NOR parts (e.g. W25Q, GD25Q) lack it or use 0x81 for something else, and the ESP32, RP2040 and nRF52840 QSPI transports reject it. Use eraseSector() for the 4KB erase.

Parameters

Returns
true if success
